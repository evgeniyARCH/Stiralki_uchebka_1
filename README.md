# Stiralki_uchebka_1
Бот для записи в учебку и/или на стирку для общежития

# Разработчик
Коркин Евгений - на "пути к себе"

# Возможности
- Запись в учебную комнату общежития на определенный день и время
- Запись на стирку на определенный день, машинку и время
- Удаление соответствующей записи/ей
- Автоматическое обновление актуальных дней для записи

# Способ реализации
Бот социальной сети VK

# Расширенные возможности для администраторов
- Отключение в включение стиральной/ых машинки/ок через бота
- Удаление любой актуальной записи
- Изменение любой/ых реплики/к через бота, без необходимости перезапускать его
- Просмотр логов записей
